
#  Dépôt de Test Git

Ce dépôt est un espace d'expérimentation temporaire pour pratiquer les commandes Git et réaliser des tests de branches pour les demonstrations .

## Fichiers du projet

- `Doc.md` : Description du dépôt.
- `main.py` : Fichier de code pour tester les modifications et les fusions.

## Commandes utiles

- Voir l'état du dépôt : `git status`
- Voir le graphe des commits : `git log --graph --oneline --all`
- Changer de branche : `git checkout <nom-de-branche>`
